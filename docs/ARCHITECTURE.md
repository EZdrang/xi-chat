# 架构：它是怎么「记得」和「像个人」的

一句话：**模型只负责说话。记忆、状态、时间、偏好都在磁盘上，不在模型里。**

所以换模型它还是它——这也是「人格不在提示词里」的验证方式。

## 分层

```
┌─────────────────────────────────────────┐
│ 模型（deepseek-flash / 任意 OpenAI 兼容） │  ← 可替换，只做语言
└───────────────▲─────────────────────────┘
                │ 每轮拼一段 prompt
┌───────────────┴─────────────────────────┐
│ 上下文组装（memory.js + state.js + mind.js）│
│  人格 SOUL · 记忆目录 · 常驻页            │
│  此刻状态 · 今天第一句 · 偏好 · 旧事       │
│  忽然想起 · 口头禅                        │
└───────────────▲─────────────────────────┘
                │ 读写
┌───────────────┴─────────────────────────┐
│ SQLite：pages / logs / sessions /         │
│         pages_fts / state / recall /      │
│         prefs / events / habits           │
│  ＋ md 文件（导入导出、跟桌面互通）        │
└─────────────────────────────────────────┘
```

## 各模块职责

| 模块 | 干什么 |
|---|---|
| `memory.js` | 记忆页读写、索引派生、三方合并、prompt 组装（人格 + 目录 + 常驻页 + 技能） |
| `state.js` | 精力 / 心情 / 温度 / 闷；按时间衰减、按对话推；规则版夜间整理 |
| `mind.js` | 时间感（recall 表）、偏好（prefs 表）、事件簿（events 表）、口头禅（habits 表） |
| `nightly.js` | 夜间整理的提示词与 JSON 解析 |
| `soul.js` | 人格门禁：核心三节 + 字数/行数阈值 |
| `app.js` | 会话、流式渲染、附件、设置、回头审阅、各种指令 |

## 关键设计

### 1. 状态不是台词，是起点

`state.js` 维护四个数。熬夜聊会掉精力，被夸会涨心情，被骂会掉并且降温，离线越久恢复越多。注入时只给一句人话（「有点乏；情绪偏低」），不给数字——数字是给自己看的，不是让它背台词。

### 2. 时间感用对数衰减

`recall` 表记「上次想起 / 想起过几次」。选页评分：

```
score = (3 - salience) × 1.5 + ln(天数 + 1) × 2.2 + random(0..1.6)
```

刚想起过的扣 4 分。久不碰的页会浮上来，且超过 30 天会带一句「印象有点糊」。

### 3. 偏好是攒的，不是设的

每轮看话题命中（技术/游戏/情感/身体/工作/八卦），再看它回得多不多：长或有表情 +1，敷衍短答 −0.8。攒够了才形成一句「最近对技术有劲儿，对八卦有点敷衍」。

### 4. 事件簿记具体的事

强信号（对不起 / 分手 / 答应 / 崩 / 和好…）当场抓原话 + 它怎么回的 + 话题标签；夜里再让模型补三条更细的。下次说到同类事，把旧事翻出来。

### 5. 夜间整理：模型出方案，代码执行

一次请求（flash）拿回 JSON：合并哪些页、哪里有分歧、日记写什么、哪些事件值得记。代码只执行，并且：

- `SOUL.md` 走门禁（见下），`MEMORY.md` 一律不动；
- 每页动手前留三版旧文，能整页回滚；
- 失败就退回规则版，至少把日记写上。

### 6. 人格门禁

小改自决、大改提案。小改的判定：核心三节（身份 / 核心价值观 / 边界）都在、字数浮动 ≤400、行级改动 ≤6。

- 通过 → 备份、生效、记时间线、下次打开主动告知；
- 不通过 → 写成 `identity/想改人格.md` 提案，等人点头。

这不是不信任它，是承认「凌晨三点基于切片视角重写人格」这件事本身风险太大。

### 7. 回头看一眼

回复落地后，以 `p(mood)` 的概率再问一次模型：这段话像不像你、有没有说重、有没有漏。有就补一句。这是「话不是一次成型」的机制。

## 桌面端对应

桌面没有常驻循环，所以同样的逻辑拆成命令：

| 命令 | 对应手机 |
|---|---|
| `tools/mind.js brief` | 跨天首句 / 会忘 / 忽然想起 / 口头禅 |
| `tools/mind.js turn "他" "我"` | 一轮结束后的偏好、事件、习惯更新 |
| `tools/state.js show\|turn\|nightly` | 状态与规则版夜间整理 |
| `tools/soul.js check\|apply` | 人格门禁 |
| `tools/memory-db.js index\|search` | SQLite FTS5 索引（桌面记忆是 md，索引可重建） |
| `tools/desk-sync.js import` | 手机记忆包三方合并 |
