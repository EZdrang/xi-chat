## 汐 · 手机版 v1.6

### 图片入口独立 + 系统相册

之前图片和文件都挤在同一个「+」里。现在拆开：

- **图片按钮**：直接开系统相册（Android 13+ 走 Photo Picker，老系统走相册的 `ACTION_PICK`）
- **文件按钮**：还是文件选择器，文档、代码、PDF 都行

相册返回的 URI 常常没有扩展名，原生侧按 MIME 补一个，否则会被当成二进制附件、发不出图。

### 余额

抽屉底部和「设置 → 图片」那一栏都会显示账户余额：

- 走 `GET {base}/user/balance`（DeepSeek 的接口，自动去掉 `/v1`）
- 显示总余额、赠送、充值三档
- 点一下余额就刷新；保存设置时也会自动刷新
- 不支持的接口会显示「不可用」，不会报错打断你

### 其他

- 画图入口从顶栏挪到「设置 → 图片 → 打开画布」，不占聊天界面
- 构建脚本：SDK 自动探测、全英文提示、按退出码判断

### 安装

下载 `xi-chat-v1.6.apk`，覆盖安装（versionCode 7），数据保留。
