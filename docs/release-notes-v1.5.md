## 汐 · 手机版 v1.5

### 新东西：画图

右上角画笔 → 写描述 → 生成。用的是**独立的 `/images/generations` 接口**，模型在「设置 → 图片」里单独配，接口地址和 Key 跟聊天共用。

- 三种尺寸：方形 1024 / 横版 1792×1024 / 竖版 1024×1792
- 一次 1–2 张
- 出图可以**直接发进对话**，也可以**存到相册**（`Download/汐/`）
- 兼容 `gpt-image-1` / `dall-e-3` / `SiliconFlow` 之类的返回：`b64_json` 和 `url` 两种都认
- 返回 URL 时走原生下载，不在 JS 里拼二进制（省得编码损坏）

### 修的

- 构建脚本：SDK 自动探测（不再写死路径）、全英文提示（PowerShell 5.1 读 UTF-8 会乱码）、stderr 告警不再当致命错误
- 之前 `javac` 的「过时 API」提示会让构建中断，现在按退出码判断

### 安装

下载 `xi-chat-v1.5.apk`，覆盖安装即可（versionCode 6）。

上一版记忆、对话、设置都保留。
