## 汐 · 手机版 v1.4

一个**有长线记忆的手机聊天 App**：记忆是纯 markdown，和桌面 DSH 的记忆库同一套格式，可以整包互相导入、按页三方合并。

### 这次有什么

- **纯聊天**：没有工具调用、没有代码执行、没有审批弹窗
- **长线记忆**：`SOUL.md` / `MEMORY.md` / `index.md` / `log.md` + 分类页；每 N 轮后台自动抽取，不打断聊天
- **三方合并同步**：导出 zip（含 `_sync.json` 每页哈希），导入时逐页判 `新增 / 远端更新 / 自动合并 / 本地领先 / 冲突 / 远端删除`；两边改到同一行才叫冲突，可让模型合成一版，最坏本地保留、远端另存 `conflicts/`
- **自动上下文压缩**：超阈值先把旧对话摘成摘要，再带着摘要继续
- **对话技能**：从 GitHub 装 `SKILL.md`，按触发词注入；也可以在聊天里让我装
- **多模态**：发图（自动缩到 1280px）/ 发文件（文本内联）
- **语音输入**：录音后交给 whisper 类接口转写，可切回系统识别
- **用量可见**：每条回复带 ↑输入 ↓输出 · 缓存命中率
- **深色模式**：跟随系统或手动切

### 安装

下载下方的 `xi-chat-v1.4.0.apk`，允许「安装未知来源应用」后装上。

- 最低 Android 7.0（API 24）
- 首次打开会生成一份初始人格，**去设置里填自己的 API Key**（任何 OpenAI 兼容接口都行）
- 记忆只在本机；想跟电脑同步，用「记忆库 → 导出记忆 zip」
