# 汐 · 手机版 2.0

这一版加的不是功能，是「像个人」的几处机制。

## 会回头看一眼

她说完话，会自己再读一遍。像不像自己、说重了没有、漏了要紧的没有——不对劲就补一句「……算了，刚才那句说重了」，或者干脆重说。你情绪重的时候触发得多，平时偶尔。

## 今天第一句话不一样

距上次说话跨了天，她会知道「这是你们今天第一次说话，距上次多少小时」。开场不再是重新开机的那种腔调。

## 她会忘

三十天没翻过的记忆会发糊。提起来时她先说「我记得好像是」，不再一口咬定。这一条比多记十条更像人。

## 口头禅是长出来的

统计她自己回复里反复出现的语气词、标点习惯、爱用的表情，攒成「你最近爱说『行吧』、爱用 😌」。用不用、用哪个、什么时候用，都看她心情。

## 桌面端同步

桌面汐多了 `tools/mind.js brief`：开场跑一次，拿到跨天首句、糊掉的旧页、忽然想起的两页、自己的口头禅；翻过的页用 `touch` 记下。这套写进了记忆库的常驻技能页。

## 底子（延续 1.x）

聊天、SQLite 记忆、联网搜索（DeepSeek 全家桶）、看图、语音转写（WAV → /v1/tools/asr）、状态（精力/心情/温度）、夜间整理（模型出方案、代码执行，人格走门禁）、事件簿、偏好。

## 没做的

- 主动发消息：她会自己弹消息那件事，元首觉得诡异，撤了。
- 空闲时的走神：需要后台常驻，代价大，先搁着。
