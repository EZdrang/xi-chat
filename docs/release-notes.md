## v2.0.0 · 2026-11-17

**从「记得住」到「像个人」的四件事。**

- 会回头看一眼：回复后自查，不对劲补一句或重说（情绪重时更常触发）
- 今天第一句话不一样：跨天首轮带「距上次多久」
- 会忘：30 天没翻的记忆标「印象有点糊」，说话留余地
- 口头禅：统计它自己用出来的词和表情，攒成倾向
- 桌面端补齐：`tools/mind.js`、`tools/soul.js`、`tools/state.js`，与手机同一套阈值
- 文档：README、ARCHITECTURE 同步到 2.0
